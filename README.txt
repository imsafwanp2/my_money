MY MONEY PWA

Files:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

Upload all five files together to the root of your GitHub Pages repository.

After GitHub Pages is enabled:
1. Open the site in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open My Money from the new icon.

Important:
This version is installable, but it still stores budget data locally in the browser.
For cross-device syncing, the next step is connecting Supabase.
